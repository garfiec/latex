# Test corpus

Formula lists used by the robustness tests in `latex-parser` and `latex-renderer`
(`src/jvmTest/.../robustness`). Nothing here ships in a published artifact.

One formula per line. Blank lines and lines whose first non-whitespace character is
`#` or `%` are comments.

## `ratex/`

Copied from [RaTeX](https://github.com/erweixin/RaTeX) at commit
`c98ae9d128a3c0a26176b3f3541f3411c4e7c3d6` (v0.1.16), MIT License, Copyright (c) erweixin.

| File | Source in RaTeX |
|------|-----------------|
| `main.txt` | `tests/golden/test_cases.txt` (KaTeX-aligned golden suite) |
| `parser.txt` | `tools/parser_compare/test_cases.txt` |
| `mhchem.txt` | `tests/golden/test_case_ce.txt` |
| `centernot.txt` | `tests/golden/test_cases_centernot.txt` |
| `prooftree.txt` | `tests/golden/test_cases_prooftree.txt` |
| `slashed.txt` | `tests/golden/test_cases_slashed.txt` |
| `unit-inputs.txt` | String literals extracted from the Rust unit tests of `ratex-lexer`, `ratex-parser` and `ratex-layout`, minus formulas already in the files above. Many are deliberately malformed. |

`unsupported-baseline.txt` is generated by this project: the corpus formulas (excluding
`unit-inputs.txt`) that currently parse with an error. The coverage test fails when a formula
is added to it and reports formulas that have left it. Regenerate it with:

```bash
UPDATE_CORPUS_BASELINE=1 ./gradlew :latex-parser:jvmTest --tests "*CorpusParseTest*"
```
